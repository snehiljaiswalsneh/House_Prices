# House Prices — Exploratory Data Analysis

This project focuses on Exploratory Data Analysis (EDA) of the **House Prices: Advanced Regression Techniques** dataset from Kaggle.

The objective is to explore residential housing data and understand the relationship between different property features and their sale prices.

## Dataset

- **Source:** [Kaggle – House Prices](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data)
- **Location:** Ames, Iowa, USA
- **Records:** 1,460 houses
- **Features:** 80 input features
- **Target Variable:** `SalePrice`

The dataset contains information about residential properties, including their size, quality, location and other characteristics.
